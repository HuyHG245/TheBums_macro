## Required Titan: Colossal Titan
**Colossal Titan is mandatory** for this Raid macro. Equip the Colossal Titan shifting form before starting; the after-Shift abilities and `heatwave.png` detection depend on this form.

## Auto Skip Cutscenes
In **Settings > Macros > Attack Titan Raid Fritz > Edit configs**, enable or disable **Auto skip cutscenes**.
When enabled, the macro detects `skip.png` and presses **E** (the same Skip input used by Female Raid).
The detector runs while waiting for the raid to start and during the Phase 1 cutscene after Colossal Shift. Disable it to let cutscenes play out normally.

## Attack Titan Raid Fritz - Opening Input Sequence
The macro waits for `acoustic_shells.png` (Skill 2 icon) to appear on the HUD.
A directional Dash uses a **double-tap of its own direction key**. No Space modifier is used.
The gap between the first two Right Dashes is **1.3 seconds** by default (configurable). Later side-Dash pauses are **0.3 seconds** by default; the macro uses explicit waits rather than a global cooldown.

1. **Right Dash #1:** D, D.
2. **Right Dash #2:** D, D after the Dash cooldown.
3. **Skill 1 - Flashbang**.
4. **Look down**: use the same CTRL → relative mouse down → CTRL camera action as Universal. Adjust the time and pixels in Edit configs > Attack Titan Raid.
5. **Back Dash:** S, S.
6. **Skill 3**, then wait **3 seconds** for its animation.
7. **Left Dash:** A, A, then wait **0.3 seconds**.
8. **Skill 2 (Acoustic Shells)**.
9. **Right Dash:** D, D, then wait **0.3 seconds**.
10. **Left Dash:** A, A, then wait **0.3 seconds**.
11. Wait an additional **1 second**, then **Skill 4**.
12. Wait **0.5 seconds** for Skill 4's animation, then **Skill 1** again.
13. Repeat **Skill 5** until `heatwave.png` confirms the Colossal Titan Shift.
14. If a Phase 1 cutscene appears, skip it automatically if enabled, otherwise wait for it to finish.
15. Begin Colossal combat. The macro automatically handles **Skill 4 Heatwave**, while **Skills 5, 3, and 1** run on independent cooldown schedules.

## Shift confirmation and Retry
The macro **continues pressing Skill 5 while the Raid is active** until `heatwave.png`
confirms Colossal Shift. There is no Shift-confirmation timeout and no automatic
recovery solely because Heatwave was not detected. When a real Retry button appears,
the existing result/loot handler processes the end screen and starts the next Raid.
Press F7 to stop manually at any time.

## Always-on Retry Watchdog
Every macro runs a passive, low-rate Retry observer that never sends inputs. If a confirmed
Retry button appears during combat, the existing macro thread handles the end screen as usual.
After clicking Retry, the macro waits briefly before accepting another Retry sighting, then
re-clicks without counting the same mission or loot twice if the result panel is still visible.

## Attack Titan Raid Loot
- **Primordial Evil**: recognized using `loot_attack_vessel.png`; counted as an Attack Titan Vessel.
- **Attack Serum**: recognized using `loot_attack_serum.png`; counted as an Attack Serum.
- Both images are included in **Settings > Detection > Fix Image Detection** for image detection calibration.
- Loot recognition is performed at the results screen; it uses confidence checks and does not infer an item from an unsuccessful Shift.

## Edit Configs and Saving
Open **Settings > Macros**, select the macro you want, then click **Edit configs**.
The editor opens the selected macro's own settings, not the last mode you edited.
Use the dropdown to switch between **that macro** and its **Shared controls**.
Shared controls include only the movement/retry settings that the chosen macro actually uses.
Changes to shared controls now override values for the **selected macro only**.
Existing global Movement values remain the fallback for configurations migrated from older versions.
Each change is validated and saved automatically to `config.json` in The Bums data folder,
under its own macro name. Settings for other macros are preserved.
**Reset shown settings** resets only the visible entries; it does not erase other
macros' timing values or hidden chest coordinates. The settings are loaded on the next launch.
For a custom macro, the Edit button opens the custom script editor because script commands
and their delays are the saved configuration for that macro.
