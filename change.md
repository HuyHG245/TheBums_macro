# Changelog

## Latest (v1.1)
- build.bat makes a single TheBums.exe with no console window behind it
- On Start the macro finds the Roblox window, watches the monitor it is on and tells you in the log if Roblox does not fill the screen
- Settings: switching tabs no longer leaves ghost images behind, and a theme change redraws the window once it is complete
- New icons for scrolls, vessels, fragments and serums
- If the program stops because of an error, the details are saved in crash.log

## v1.0
- New name, logo and icon
- Opacity slider in the footer, 30-100 %, remembered between runs
- No online update check: the only network use is the Discord webhook you set up yourself

## Features
- Mission macro with the Shiki, Universal, Blood and Female Raid builds
- Guides section with a build guide for each one
- Loot tracking: scrolls, fragments, serums and vessels, with a Details section
- Settings window (hotkeys, chest buttons, themes), Edit configs window for timings, asset override tab
- Stats: missions, completed, failed, mission time, run time, activity log
- Small stats bar mode
- Discord webhook with stats and screenshots
- Ten themes
- Always on top switch
